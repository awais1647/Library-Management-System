# Library Management System

## Project Overview

The Library Management System is a basic full-stack system architecture designed to manage library operations.

The system has two separate panels:

* **Admin Panel:** Used to manage books, users, and borrowing records.
* **User Panel:** Used to browse and search books, check availability, and request books.

Both panels communicate with a shared backend through APIs and use a common database.
